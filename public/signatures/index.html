Email signatures

Pick a signature and click Copy signature, then paste it into your email client's signature settings. Use Full for new emails and Compact for replies and forwards.

How to install

  1. Gmail: Settings (gear) → See all settings → General → Signature → Create new → paste → Save changes at the bottom.
  2. Outlook (web and new Outlook): Settings → Account → Signatures → New signature → paste → Save. Choose it under "Select default signatures".
  3. Apple Mail: Mail → Settings → Signatures → + → uncheck "Always match my default message font" → paste → close the window.
  4. Clients that ask for HTML (Thunderbird, Spark, HubSpot, etc.): use Copy HTML and paste the code in the HTML/source field.
